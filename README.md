### ALGO-000164: A polynomial pivot rule for the simplex method
- **Subfield:** Linear optimization and enumeration
- **Open:** Find a simplex pivot rule with a worst-case polynomial bound on the number of pivots for all linear programs, including a polynomially controlled initialization procedure.
- **Status:** Many natural rules have exponential examples. Polynomial polytope diameter alone would not supply an efficiently computable rule.
- **Type:** theory
- **Why:** Would provide worst-case theory matching the practical success of simplex-style optimization.
- **Key works:** Klee and Minty (1972), *How Good Is the Simplex Algorithm?*; Kalai (1992), randomized pivoting; Spielman and Teng (2004), smoothed analysis.
- **Related:** Numerical optimization—worst-case versus typical performance.
